# Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone.

Be respectful and constructive, focus criticism on ideas and code, accept feedback gracefully, and respect privacy. Harassment, discrimination, threats, deliberate intimidation, publishing private information, and sustained disruptive behavior are not tolerated.

Report conduct concerns privately to the repository owner through GitHub. The maintainer may edit or remove contributions and restrict participation when necessary.
