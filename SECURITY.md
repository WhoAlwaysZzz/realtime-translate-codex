# Security Policy

Security fixes are applied to the latest code on the default branch.

Do not open a public issue for a vulnerability or exposed credential. Use GitHub's private vulnerability reporting and include the affected version, reproduction steps, impact, and suggested mitigation.

The project stores screenshots, OCR records, lookup history, and optional AI configuration under `%LOCALAPPDATA%\RealtimeTranslateCodex`. These files remain local unless explicitly shared. Selected sentence text is sent to the configured AI provider only when sentence explanation is used.
