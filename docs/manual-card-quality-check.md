# 人工检测卡片质量

## 直接启动真实程序

Release 程序位于：

`src/RealtimeTranslate.App/bin/Release/net8.0-windows10.0.19041.0/RealtimeTranslate.App.exe`

启动后在任意可见英文窗口中用右键拖选一小段文字。重点观察：

- 首屏是否先给出当前句中的自然含义；
- 上下文错误或乱码时，是否明确标记“不使用上下文”，而不是自信猜测；
- 学习层是否提供了这个词本身的可靠概念、搭配或词形线索；
- 学习信息是否只是重复中文释义或空泛记忆故事。

## 使用真实归档复现

循环每轮的报告位于：

`docs/loop-reports/iteration-<n>.md`

报告中列出的 before/after 样例应与对应的截图和产物一起检查。不要把 OCR 非空或单元测试通过当成卡片质量通过。

## 人工判定

对每张卡只回答两个问题：

1. 只看首屏，我能否继续读懂这句剧情？
2. 看学习层，我是否更理解这个英文词本身，而不是只记住一个中文答案？

若答案是否定的，请记录具体是哪一层错误、缺失、冗长或具有误导性。
