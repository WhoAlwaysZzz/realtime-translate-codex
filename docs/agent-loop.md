# Agent Loop for Realtime Translate Codex

本项目采用持续的 agent loop，而不是把每条用户消息当成独立的一次性任务。

## 每轮循环

1. **计划**：从原始目标和当前证据中选择一个最小、可验证的改动。
2. **执行**：实现改动，并保持生产路径与回放路径共用核心逻辑。
3. **验证**：构建项目，然后用真实归档、真实 OCR 或用户可见界面验证结果。
4. **反思**：记录实际失败原因，区分代码缺陷、环境限制、输入质量和产品判断问题。
5. **进入下一轮**：只把已证实的经验带入下一轮，不把临时猜测升级成需求。

## 证据要求

- 单元测试只能证明局部逻辑，不代表工具对用户有用。
- 回放测试必须使用真实历史截图和生产查词流水线。
- 卡片内容质量需要人工标注样本；模型不能自行把答案判定为真值。
- 每轮记录构建结果、运行结果、失败样本和下一步假设。

## 停止条件

只有在以下情况才暂停循环：目标已达到；继续工作只剩低价值打磨；需要用户提供无法推断的偏好或权限；或连续三轮没有新的证据和进展。

当前循环目标：让历史截图能够完成 `PNG → 裁剪 → Windows OCR → 查词 → 实际卡片` 的生产回放。
