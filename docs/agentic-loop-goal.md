# Agentic Loop: 可靠上下文 OCR + 能帮助记忆的单词卡

## 目标

工具必须同时解决两件事：

1. 用户马上理解当前游戏句子中该词的意思；
2. 用户随后能理解并记住这个词本身，而非只记住这一次的中文答案。

错误或乱码的上下文绝不能驱动释义。反过来，正确的本句义也不应挤掉对单词核心概念、搭配和记忆线索的解释。

## 上下文 OCR 的量化门槛

建立至少 50 条真实游戏截图的金标准语料。每条记录截图、选词、人工转录的目标字幕行、关键内容词、可接受断句；两个独立 agent 的盲转写一致才计入金标准，分歧样本标为 `uncertain`，不得伪造真值。

- 目标所在字幕行恢复率 ≥95%；
- 上下文 normalized WER ≤8%，或关键内容词准确率 ≥92%；
- `ContextQualityGate` 对“可安全用于推义”的 precision ≥95%、recall ≥85%；
- 依赖上下文的词义 Top-1 ≥90%；低质量上下文强行影响主释义为 0；
- P95 从松开选择到基础卡 ≤2 秒。

必须探索并按实证选择：行级 OCR 输出（含几何位置）、多尺度与多预处理结果、候选行融合、以选区为锚点的字幕区裁剪、以及可信度门控。不得把首个非空 OCR 结果当作成功；不得通过词典猜测伪造 OCR 原文；低可信上下文必须明确降级。

## 学习型卡片的完成定义

卡片分为两层：

- **首屏（继续读剧情）**：原词/词形、当前句义、词性、短语或句子功能、上下文可信状态。最多五块；网络不可用也必须出现。
- **学习层（记住这个词）**：只保留经证据支持、最有助记忆的 1–2 项：词的核心概念、常见搭配/短语、可信的词形关系或构词线索、以及一个能区分易混义项的例子。它不能是空泛的 AI 套话、冗长词典复制或不可靠词源故事。

实现时允许替换词典数据结构、增加带来源的 `LearningInsight`、使用不同 OCR/词典/模型服务。但每条学习信息必须标记来源和置信度；AI 增强只能异步出现，失败时不影响首屏。

## 学习质量量化门槛

对至少 30 个真实游戏词建立学习评测集（含普通词、抽象词、词形变化、搭配、专有称谓和多义词）。每项有可验证的核心释义、至少一个不可接受的空泛/错误解释及来源。

- 独立评委对“首屏可继续阅读”判定通过 ≥90%；
- 独立评委对“学习层能帮助理解词本身而非重复中文释义”判定通过 ≥80%；
- 学习层事实/来源错误为 0；空泛、无证据或重复信息比例 ≤10%；
- 至少 70% 样本提供一条有用且可信的记忆线索；其余必须诚实省略，不能硬凑。

## 独立评委与停止条件

对每个改变 OCR、上下文选择、可信度或学习卡架构的提交，runner 启动一个全新、只读 reviewer agent。评委必须审查截图、金标准、前后输出和实际卡片，只能输出 `accept`、`reject` 或 `insufficient-evidence`，不能修改文件，也不能仅凭实现者的文字或单元测试认可方案。

达到全部 OCR 与学习门槛，并在两批未参与开发的样本上连续获得两个独立评委 `accept` 后，agent 创建 `docs/agent-loop.auto-accepted.md` 写明证据与两份评审报告，runner 自动停止。这是自动研究完成，不等同于用户最终验收。

每轮只解决最高价值差距；不删除用户文件、归档截图或历史记录；不回到托盘、热键等无关工作。
